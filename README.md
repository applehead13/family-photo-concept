# Полина Гусева — портфолио

Сайт перенесён из экспорта Tilda без изменений вёрстки, текстов, картинок и эффектов. Адаптивные версии (1200 / 768 / 360) работают так же, как на Tilda.

Что добавлено к экспорту:
- внешние скрипты (GSAP, ScrollTrigger, SmoothScroll) лежат локально в `js/vendor/`;
- шрифты подключаются из `fonts/`;
- невидимые якоря для ссылок меню, которые в экспорте указывали на старые id блоков;
- убраны статистика Tilda и плашка «Made on Tilda».

Публикация: GitHub Pages, ветка `main`, папка `/` (root).
